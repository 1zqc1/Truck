# Truck — 液罐半挂车侧翻预警研究

本仓库用于管理液罐半挂车侧翻预警研究中的可复现源码、配置、研究设计和实验日志。

## 当前主线

- TruckSim：牵引车—三轴半挂车整车动力学与完整轴组轮载参考；
- Fluent：二维 VOF 液体晃动离线高保真参考；
- MATLAB/Simulink：五自由度车辆模型、一阶降阶晃动模型与轻量预警修正；
- 耦合架构：先采用 Fluent 离线参考 + Simulink ROM + TruckSim，接口预留未来 CFD 回放、松耦合和逐时间步 CFD–车辆动力学双向耦合。

架构规格见：

- `docs/superpowers/specs/2026-09-21-tanker-slosh-upgradable-coupling-design.md`
- `01_论文与研究设计/液罐半挂车五自由度侧翻预警_最终研究方案与执行流程_v1.md`

## 目录

- `00_项目索引/`：项目入口与文件清单；
- `01_论文与研究设计/`：研究问题、方案和审计材料；
- `02_文献与证据/`：文献证据矩阵与核查脚本；
- `03_Fluent当前算例/`：本地 Fluent 算例位置，大型结果不进入 Git；
- `04_UDF/`：Fluent UDF 源码；
- `05_网格与Workbench/`：网格与 Workbench 自动化脚本；
- `06_车辆模型与MATLAB代码/`：TruckSim 配置、MATLAB/Simulink 和处理代码；
- `实验日志/`：可追踪实验日志和索引；
- `raw/`：本地原始结果归档，不进入 Git。

## 数据策略

Git 只保存源码、Markdown、轻量配置和小型模型。原始 CSV、Fluent `cas/dat`、Workbench 缓存、编译产物和历史大型 MATLAB 数据保留在本地，并由实验日志记录路径与 SHA-256。必要的大型发布数据应使用独立数据仓库或版本化发布包，不应直接加入普通 Git 历史。

## 证据边界

`07_历史数据_仅审计不可作新论文证据/` 中的数据和模型仅供审计与接口回归，不用于新论文性能结论。当前45°阶跃速度扫描属于 TruckSim 输出与边界校准，也不属于液体晃动正式证据。

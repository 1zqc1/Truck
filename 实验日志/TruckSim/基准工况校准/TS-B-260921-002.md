# TS-B-260921-002：45°阶跃转向基准校准

## 目的

将原示例中实际为 120° 的转向输入复制到项目库并修正为 45°，验证新过程、新输入和精简输出通道的回连关系，同时判断 100 km/h 下该输入是否能产生接近侧翻边界但不发生车轮离地的动态响应。

## 配置

- 目标车速：100 km/h。
- 仿真时段：0–15 s。
- 方向盘转角：0–10 s 为 0°；10.0–10.1 s 从 0°线性增加到 45°；其后保持 45°。
- 挂车完整轴组：全车第 4–6 轴。
- 输出：时间列及 18 个精简变量。
- LTR 定义：

  \[
  LTR=\frac{(F_{z,R4}+F_{z,R5}+F_{z,R6})-(F_{z,L4}+F_{z,L5}+F_{z,L6})}
  {(F_{z,R4}+F_{z,R5}+F_{z,R6})+(F_{z,L4}+F_{z,L5}+F_{z,L6})}
  \]

## 数据完整性

- CSV：601 行、19 列（`Time` 加 18 个变量）。
- 时间范围：0–15 s。
- 采样间隔：0.025 s。
- 缺失值：0。
- 停止原因：达到设定停止时间，未触发侧倾极限终止。

## 主要结果

| 指标 | 结果 |
|---|---:|
| 峰值 `|LTR|` | 0.758998 |
| 峰值时刻 | 11.725 s |
| `|LTR|` 首次达到 0.3 | 10.700 s |
| `|LTR|` 首次达到 0.5 | 10.900 s |
| 14–15 s 平均 LTR | 0.681603 |
| 14–15 s LTR 标准差 | 0.000810 |
| 峰值相对末段均值超调 | 11.355% |
| 峰值侧向加速度 | 0.299279 g |
| 峰值挂车侧倾角 | 2.797316° |
| 峰值挂车侧倾角速度 | 3.615223°/s |

峰值 LTR 时，挂车左侧三轮载分别为 12.397、11.246、10.269 kN，右侧分别为 81.344、82.567、83.606 kN。六个轮载均保持正值，因此本工况没有发生车轮离地。

## 解释与证据边界

1. 45°、100 km/h 工况能够形成较高但未到轮胎离地的载荷转移，可作为后续速度扫描的近边界校准点。
2. LTR 瞬态峰值比 14–15 s 的近稳态均值高约 11.4%，说明仅采用稳态值可能低估本次阶跃输入下的瞬态风险。该结果只是单工况现象，尚不能直接证明动态安全速度方法整体优于静态安全速度方法。
3. 当前载荷仍是矩形箱式固定载荷，并非液体晃动模型，因此不能将本结果归因于液体晃动。
4. 日志存在轮胎松弛长度和回正力矩表的少量外推提示；转向输入表在 11 s 后采用外推保持 45°。正式批量试验前应把末行时间扩展到 15 s，并继续核查轮胎表外推范围。

## 下一步

1. 将转向输入末行从 `(11 s, 45°)` 改为 `(15 s, 45°)`，消除转向表超范围外推提示。
2. 保持 45°输入，建立车速扫描副本，优先测试 80、90、100、110 km/h，定位 `max|LTR|` 接近 0.8、0.9 和车轮离地的区间。
3. 在液体模型接入前，将本试验仅作为固定载荷基线，不作为晃动修正方法的正式验证数据。

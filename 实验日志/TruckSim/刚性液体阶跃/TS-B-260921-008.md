# TS-B-260921-008：F30 刚性液体 60 km/h 阶跃转向基线

## 目的

建立 30% 液位刚性等效液体模型的低风险动态基线，用于后续与 70% 液位以及液体晃动降阶模型比较。

## 工况

- 车辆组合：`Tanker_6Axle_Combination`
- 挂车干车簧载质量：`Tanker_3A_DrySprungMass_v1`
- 液体载荷：`Tanker_LiquidRigid_F30_v1`
- 液体质量：`7860 kg`
- 液体重心：`X = 6000 mm`，`Y = 0 mm`，`Z = 1738.1 mm`
- 目标车速：`60 km/h`
- 方向盘输入：`0–10 s = 0 deg`，`10–10.1 s = 0→45 deg`，`10.1–16 s = 45 deg`
- 路面附着系数：`0.85`
- 仿真时长：`16 s`
- 输出采样间隔：`0.025 s`

## 结果

对 `15–16 s` 稳态窗口统计：

- 平均车速：`59.9877 km/h`
- 平均横向加速度：`0.182008 g`
- 挂车平均侧倾角：`0.320573 deg`
- 平均 LTR：`0.295288`
- 全程最大绝对 LTR：`0.295419`
- 内侧三轮总载荷：`40.073 kN`
- 外侧三轮总载荷：`73.656 kN`
- 全程最小单侧轮位载荷：`12.402 kN`
- 平均挂车横摆角速度：`6.13758 deg/s`
- 平均铰接角：`-2.95816 deg`

全程六个轮位竖向力均大于零。最后 1 s 的 `LTR` 标准差为 `0.0000855`，横向加速度标准差为 `0.0000548 g`，响应已进入稳定平台。本结果仅作为刚性等效液体基线，不代表真实液体晃动工况。

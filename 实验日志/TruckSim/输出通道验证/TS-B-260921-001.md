# TS-B-260921-001 TruckSim 精简输出通道验证

## 目的

在六轴牵引车—三轴半挂车模型中确认挂车完整轴组左右轮载变量，并建立可直接供 MATLAB 读取的精简 CSV 输出。该运行只用于接口和变量映射验证，不作为论文正式工况证据。

|---|---|
| Run Control | `Tanker_6Axle_5DOF_Base` |
| 车辆组合 | `Tanker_6Axle_Combination` |

## 精简输出通道

CSV 包含自动时间列和18个指定变量，共19列：

| 类别 | 变量 | 含义 | 单位 |
|---|---|---|---|
| 挂车轴组轮载 | `Fz_L4`, `Fz_R4` | 挂车第1轴左/右侧合计轮载 | N |
| 挂车轴组轮载 | `Fz_L5`, `Fz_R5` | 挂车第2轴左/右侧合计轮载 | N |
| 挂车轴组轮载 | `Fz_L6`, `Fz_R6` | 挂车第3轴左/右侧合计轮载 | N |
| 挂车姿态 | `Roll_2` | 挂车侧倾角 | deg |
| 挂车姿态 | `AVx_2` | 挂车车体系侧倾角速度 | deg/s |
| 挂车运动 | `Ay_2` | 挂车瞬时总质心横向加速度 | g |
| 挂车运动 | `Vx_2` | 挂车瞬时总质心纵向速度 | km/h |
| 挂车运动 | `AVz_2` | 挂车车体系横摆角速度 | deg/s |
| 操纵输入 | `Steer_SW` | 方向盘转角 | deg |
| 铰接状态 | `Art_H` | 第1连接点铰接角 | deg |
| 铰接状态 | `Roll_H` | 第1连接点相对侧倾角 | deg |
| 铰接状态 | `RollR_H` | 第1连接点相对侧倾角速度 | deg/s |
| 铰接受力 | `Mx_H` | 第1连接点 X 向力矩 | N·m |
| 铰接受力 | `Fy_H` | 第1连接点作用于挂车的 Y 向力 | N |
| 铰接受力 | `Fz_H` | 第1连接点作用于挂车的 Z 向力 | N |

挂车完整轴组 LTR 按下式在 MATLAB 中后处理：

\[
LTR_{tr}=\frac{(Fz_{R4}+Fz_{R5}+Fz_{R6})-(Fz_{L4}+Fz_{L5}+Fz_{L6})}
{Fz_{R4}+Fz_{R5}+Fz_{R6}+Fz_{L4}+Fz_{L5}+Fz_{L6}}.
\]

本次转向方向下，LTR 为正表示右侧总轮载高于左侧总轮载。

## 诊断结果

静止初始时刻三个挂车车轴的左右合计轮载分别为：

| 全车轴号 | 挂车轴号 | 初始轴载（N） |
|---:|---:|---:|
| 4 | 1 | 111,718.12 |
| 5 | 2 | 93,939.29 |
| 6 | 3 | 76,160.47 |

三个挂车轴初始路面总支承力为281,817.88 N，初始连接点垂向力 `Fz_H` 为191,286.78 N。上述数值只用于检查力的闭合和通道有效性，尚未完成实车轴荷标定。

本次激烈转向下的事件时序为：

| 事件 | 时间（s） |
|---|---:|
| \(|LTR_{tr}|\ge 0.50\) | 10.600 |
| \(|LTR_{tr}|\ge 0.80\) | 10.750 |
| \(|LTR_{tr}|\ge 0.90\) | 10.800 |
| 挂车第3轴左侧轮载首次为0 | 10.850 |
| 挂车第2轴左侧轮载首次为0 | 10.875 |
| 挂车第1轴左侧轮载首次为0 | 10.900 |
| 求解器因 unit 2 侧倾限制终止 | 12.223 |

在首次达到 \(|LTR_{tr}|=0.8\) 的采样点（10.750 s），`Ay_2=0.3368 g`、`Vx_2=99.858 km/h`、`Roll_2=3.181 deg`、`AVx_2=8.028 deg/s`。该事件确认六个挂车轮载通道能反映连续的轮载转移和轮胎离地过程。

## 阻断项与异常

1. `Steering Step Input` 数据集标题写作“0 to 45 deg at 10 s”，但实际 `STEER_SW_TABLE` 为0→120°：10.0 s为0°，10.1 s达到120°并保持至11.0 s。正式实验前必须复制并重建研究专用过程与转向输入，不能使用该误标示例。
2. 日志在11.1985 s报告 `MX_HITCH_TABLE` 超出高端范围；当前第五轮 Roll Moment 表只定义至±2°，不能用本次翻覆后的外推段标定物理参数。
3. 多个轮胎力表和悬架限位表在激烈响应阶段发生外推。该运行只证明数据链可用，不证明车辆参数或极限响应可信。
4. 12.175 s以后左右挂车轮载均为0，属于车辆已经翻转/整体离地后的状态；预警建模应以首次轮胎离地之前的数据为主，不能把翻覆后数据当成正常动力学样本。

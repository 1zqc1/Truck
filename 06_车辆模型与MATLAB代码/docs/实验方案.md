# 实验方案

## 基于 LSTM 与差动制动的罐车侧翻预警防控系统研究

---

## 一、实验目的

1. 搭建七自由度半挂液罐车 TruckSim 高保真仿真模型，引入 LDP 双摆模型模拟液体晃动效应；
2. 设计并生成涵盖鱼钩、双移线、阶跃转向及道路横坡的多工况侧翻仿真数据集；
3. 构建 LSTM、CNN、CNN-LSTM 三种神经网络侧翻预警模型并进行对比评估；
4. 通过消融实验验证液体晃动对侧翻预测性能的影响；
5. 设计基于差动制动的防侧翻控制策略，实现"预警-防控"闭环（待完成）。

---

## 四、实验一：TruckSim 高保真建模

### 4.1 车辆模型参数

| 参数 | 牵引车 | 半挂罐车 |
|------|--------|---------|
| 质量 /kg | 7500 | 26500（空罐6500+液体20000） |
| 质心高度 /m | 1.10 | 1.80 |
| 侧倾惯量 /(kg·m²) | 4500 | 12000 |
| 横摆惯量 /(kg·m²) | 18000 | 85000 |
| 轴距 /m | 3.80 | 8.50 |
| 轮距 /m | 2.05/1.86 | 1.86 |

### 4.2 LDP 液体晃动模型参数

| 参数 | 主摆 | 次摆 |
|------|------|------|
| 质量占比 | 75%（15000kg） | 25%（5000kg） |
| 等效摆长 /m | 0.55 | 0.18 |
| 固有频率 /(rad/s) | 4.22 | 7.38 |
| 阻尼比 | 0.07 | 0.05 |

充液比 70%。LDP 状态空间为 4 阶系统 `[θ₁, θ̇₁, θ₂, θ̇₂]`，输出晃动横向力 F_slosh 和侧倾力矩 M_slosh。

### 4.3 I/O 通道配置

- **Export（18通道）**：Vx, Ay, AVz, Roll, AVx_Roll, Steer_SW, Ax, Fz_L1~R5, Ay_T
- **Import（3通道）**：IMP_FY_T, IMP_MX_T, IMP_STEER_SW

## 五、实验二：侧翻工况设计

### 5.1 工况类型

| 工况 | 组数 | 关键参数 | 物理意义 |
|------|------|---------|---------|
| 阶跃转向 SS | 12 | 60~100km/h, 60°~180° | 紧急转向 |
| 双移线 DLC | 2 | 70~100km/h | 紧急避障 |
| 鱼钩 Fishhook | 16 | 60~90km/h, 90°~270° | 极限侧翻激励 |
| 横坡叠加 Super | 7 | 80km/h, -6%~+6% | 弯道超高 |

### 5.2 鱼钩转向表设计

转向速率 720°/s，保持 0.25s，幅值 A（起始 10s）：

```
STEER_SW_TABLE LINEAR
0, 0
10, 0
10+A/720, +A          （打到 +A）
10+A/720+0.25, +A      （保持）
10+A/720+0.25+2A/720, -A  （反向到 -A）
..., -A                 （保持）
..., 0                  （回正）
ENDTABLE
```

### 5.3 横坡 dZ Map 设计

通过 `ROAD_DZ_L_TABLE` 定义横坡（L 为横向坐标，±5m）：

```
ROAD_DZ_L_TABLE LINEAR_FLAT
-5, -(X%/100)*5
0, 0
5, +(X%/100)*5
ENDTABLE
```

## 六、实验三：数据采集

### 6.1 TruckSim CLI 批量仿真

```powershell
VS_SolverWrapper_CLI_64.exe -par "仿真par文件" -datadir "TruckSim\data"
```

### 6.2 VSB → CSV 导出

- 二进制格式：24 字节头 + 每帧 nChan×4 字节（float32）
- 时间 = 帧号 × XStep（0.025s）
- 导出列：Time, Vx, Ay, AVz, Roll_E_2, Steer_SW, Fz_L1, Fz_L2, Fz_R1, Fz_R2

### 6.3 LTR 标签计算

```
LTR = (Fz_L1+Fz_L2 - Fz_R1-Fz_R2) / (Fz_L1+Fz_L2+Fz_R1+Fz_R2)
```

阈值：|LTR| ≥ 0.7 判定为侧翻风险。

## 七、实验四：数据预处理

1. **特征提取**：Ay, AVz, Roll2, Vx, Steer_SW（5个特征）
2. **序列构建**：滑动窗口 lookback=50（0.5s），预测 horizon=10（0.1s）
3. **标准化**：Z-score（均值0，标准差1）
4. **数据划分**：60%训练 / 20%验证 / 20%测试
5. **样本平衡**：危险样本上采样至占比约30%

结果：37组工况 → 18056 个训练序列样本。

## 八、实验五：模型训练

### 8.1 LSTM 模型

```
sequenceInput(5) → LSTM(64) → Dropout(0.2) → FC(16) → ReLU → FC(1) → regression
```

### 8.2 CNN 模型

```
sequenceInput(5) → Conv1D(128,k=3) → Pool → Conv1D(64,k=3) → GlobalPool → FC(50) → Dropout → FC(1)
```

### 8.3 CNN-LSTM 模型

```
sequenceInput(5) → Conv1D(128,k=3) → Pool → LSTM(64) → LSTM(32) → FC(50) → Dropout → FC(1)
```

### 8.4 训练参数

| 参数 | 值 |
|------|-----|
| 优化器 | Adam |
| 初始学习率 | 0.001 |
| 学习率衰减 | 每20轮×0.5 |
| 最大轮数 | 80 |
| 批次大小 | 64 |
| 损失函数 | MSE |

## 九、实验六：性能评估

### 9.1 评价指标

- **回归**：RMSE、R²
- **分类**（|LTR|=0.7 阈值）：准确率、精确率、召回率、F1
- **判别**：ROC 曲线下面积 AUC

### 9.2 预期结果（已完成）

| 模型 | RMSE | R² | F1 | AUC |
|------|------|-----|-----|-----|
| LSTM | 0.0533 | 0.9784 | 0.955 | 0.9979 |
| CNN | 0.0521 | 0.9794 | 0.939 | 0.9985 |
| CNN-LSTM | 0.0485 | 0.9821 | 0.969 | 0.9988 |

## 十、实验七：消融实验

### 10.1 实验设计

同一组工况跑两次：开启 LDP（含液体晃动）vs 关闭 LDP（F_slosh=0, M_slosh=0），用相同 LSTM 架构分别训练对比。

### 10.2 预期结果（已完成）

| 动力学模型 | F1 | 准确率 |
|-----------|-----|--------|
| 含液体晃动 | 0.996 | 99.36% |
| 无液体晃动 | 0.999 | 99.87% |

结论：液体晃动使 F1 仅下降 0.003，LSTM 对晃动有强自适应能力。

## 十一、实验八：差动制动防控（待完成）

### 11.1 控制策略

1. LSTM 预测未来 |LTR| ≥ 0.7 → 触发预警；
2. 计算目标附加横摆力矩 Mz；
3. 通过单侧车轮制动力分配产生 Mz；
4. 反馈至 TruckSim 车辆模型，抑制侧翻趋势。

### 11.2 预期目标

- 预警触发后 LTR 峰值降低 ≥15%；
- 侧倾角幅值降低 ≥20%。

### 11.3 实施步骤

1. 搭建"TruckSim→LSTM预警→差动制动→回灌"闭环；
2. 验证闭环仿真稳定性；
3. 对比有/无控制下的 LTR 与侧倾角曲线。

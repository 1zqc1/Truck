# Fluent 液体晃动流固耦合仿真方案

## 基于 Ansys Fluent 2024 R2 的罐车液体晃动仿真

---

## 一、总体目标

用 Ansys Fluent 高保真模拟罐内液体晃动，得到液体对罐壁的晃动力与力矩，用于：
1. 验证/校准 LDP 等效双摆模型参数；
2. 为车辆动力学耦合提供高保真晃动输入；
3. 最终实现完整流固耦合（FSI）。

## 二、分阶段实施计划

| 阶段 | 内容 | 维度 | 目标 |
|------|------|------|------|
| 第一步 | 液体晃动 VOF 仿真（入门） | 2D 圆形 | 跑通 VOF 流程，得到晃动力 |
| 第二步 | 参数验证 | 2D | Fluent 结果 vs LDP 频率/力对比 |
| 第三步 | 3D 圆柱罐仿真 | 3D | 真实几何，纵向+横向晃动 |
| 第四步 | 动网格/系统耦合 | 3D | 罐体运动，完整 FSI |
| 第五步 | 车辆动力学耦合 | — | Fluent ↔ TruckSim/7-DOF |

## 三、第一步详细方案（2D 液体晃动 VOF）

### 3.1 几何

- 2D 圆形横截面，对应罐体真实截面
- 直径 D = 2.5 m，半径 R = 1.25 m
- 圆心坐标 (0, 0)

### 3.2 充液比与液面

- 充液比 70%（项目设定，最易诱发大幅晃动）
- 液面高度约 1.63 m（从罐底，即 y ≈ -0.87 m 处，圆心下方）

### 3.3 网格

- 四边形/三角形混合网格
- 液面附近加密（捕捉 VOF 界面）
- 建议单元尺寸 0.01~0.02 m，壁面附近更细
- 网格量约 2~5 万单元（2D）

### 3.4 物理模型

| 项目 | 设置 |
|------|------|
| 求解器 | 瞬态（Transient） |
| 多相流 | VOF（2 相） |
| 相 1 | air（气相） |
| 相 2 | water-liquid（液相） |
| 表面张力 | 0.072 N/m（可选开启） |
| 粘性模型 | 层流（Laminar） |
| 重力 | 开启，g = 9.81 m/s² |

### 3.5 材料参数

| 材料 | 密度 (kg/m³) | 动力粘度 (Pa·s) |
|------|-------------|----------------|
| air | 1.225 | 1.7894e-5 |
| water-liquid | 998.2 | 0.001003 |

### 3.6 激励方式（关键）

侧向加速度激励通过**修改重力向量方向**实现（等效加速度原理）：

- 重力 x 分量：g_x = -A·sin(2πft)（侧向激励）
- 重力 y 分量：g_y = -9.81（竖直重力）

参数：
- 激励幅值 A = 0.3g ≈ 2.94 m/s²（对应典型侧向加速度）
- 激励频率 f = 0.5 Hz（周期 2 s）

> 后续可升级为动网格（罐体真实运动）或 SystemCoupling 双向 FSI。

### 3.7 边界条件

| 边界 | 类型 | 设置 |
|------|------|------|
| 罐壁 | wall | 无滑移，接触角 90°（默认） |
| 操作压力 | — | 101325 Pa，参考位置 (0, 0) |

### 3.8 求解设置

| 项目 | 设置 |
|------|------|
| 时间步长 | 0.001 s（满足 CFL 条件） |
| 时间步数 | 2000（模拟 2 s） |
| 每步迭代 | 20 |
| 离散格式 | PRESTO!（压力），二阶迎风（动量），Geo-Reconstruct（VOF） |
| 收敛判据 | 残差 1e-4 ~ 1e-5 |

### 3.9 后处理

- 提取罐壁 x 方向受力（晃动力）随时间变化
- 输出液面形状（VOF 云图）关键帧
- 对比 LDP 模型计算的晃动频率与力

---

## 四、关键参数来源

- 罐体几何：项目 `init_params.m`（直径 2.5m）
- 充液比：70%（项目设定）
- 液体：水（代表典型液体货物）
- 激励幅值：参考 37 组 TruckSim 工况的侧向加速度（|Ay|max 0.27~1.28g）

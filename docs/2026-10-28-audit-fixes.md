# 2026-10-28 数据链审查修复

- `process_ts_data` 和 `data_export` 按完整输入文件分配训练、验证和测试数据，再仅用训练集拟合归一化参数。拆分按文件而非工况语义：必须事先确认不同文件不是相同工况、重跑或同源数据的重复，才能声称跨工况独立验证。
- 两条链要求挂车第 4–6 轴左右轮载完整、有限且非负，按 `(右 - 左) / (右 + 左)` 计算汇总 LTR；使用前须依据具体车辆输出配置核对轴位、轮载符号和单位。历史缺失轮载的文件不会静默补零或用侧倾角冒充轮载真值。
- 标签平滑使用因果窗口，TTR 外推要求当前侧倾角和角速度朝同一侧；这仍是阈值代理，不能直接视作真实侧翻时间。
- 默认拒绝覆盖已有数据集；只有调用时显式设置 `overwrite=true` 才允许覆盖。旧模型、旧训练指标和历史数据未被修改或重新认证。
- 鱼钩、横坡批处理要求参数锚点唯一、求解器成功且输出文件更新。因检测依赖文件元数据，未更新元数据时会安全地拒绝输出；尚需在实际 TruckSim 环境验证。
- 合成测试保存在 `matlab/tests`。`tests/fixtures/init_params.m` 是测试专用桩，绝不能加入生产 MATLAB 路径；这些测试不代替真实通道映射、独立工况、物理模型或预警性能验证。

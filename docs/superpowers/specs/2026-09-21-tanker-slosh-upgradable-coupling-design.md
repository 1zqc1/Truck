# 可升级液罐车晃动耦合架构设计

日期：2026-09-21  
状态：待用户审阅  
适用软件：TruckSim 2022.1、MATLAB/Simulink R2022a、ANSYS Fluent 2024 R2

## 1. 决策

主线采用“Fluent 离线参考 + Simulink 一阶降阶晃动模型 + TruckSim 车辆动力学”的方案。第一篇论文和毕业目标不依赖 Fluent–TruckSim 逐时间步双向 CFD 联算，但所有信号、单位、参考点和数据文件按可替换接口设计，使降阶晃动模块未来可被 CFD 回放、松耦合 CFD 或逐时间步 CFD 参与者替换。

该设计是现有《液罐半挂车五自由度侧翻预警：最终研究方案与执行流程 v1》的升级兼容补充，不改变其当前主线：30% 和 70% 充液率用于开发，50% 充液率用于锁定验证；研究对象仍为挂车完整轴组 LTR 和预警时刻误差。

## 2. 目标与非目标

### 2.1 目标

1. 建立质量、质心、惯量和静态轴荷闭合的三轴罐式半挂车模型。
2. 建立严格配对的 `Rigid` 与 `ROM-Slosh` 两类车辆模型，使二者差异只来自液体动态增量。
3. 用二维 Fluent VOF 数据识别并验证充液率参数化的一阶晃动模型。
4. 用统一接口向 TruckSim 挂车簧载质量施加液体横向力和滚转力矩动态增量。
5. 保留从降阶模型升级至 CFD 回放、松耦合迭代和逐时间步双向 CFD–车辆动力学耦合的路径。

### 2.2 非目标

1. 第一阶段不做罐壁结构变形。
2. 第一篇论文不以逐时间步 Fluent 联算成功为完成条件。
3. 不把 TruckSim、Fluent、Simulink 的组合本身声明为创新。
4. 不使用旧项目中未经核验的 20 t 液体、双摆质量比例或旧 LSTM 精度作为新论文证据。
5. 不将当前 18,340 kg 矩形箱式载荷直接称为液罐或刚性等效液体。

## 3. 总体架构

```text
                    ┌─────────────────────────────┐
                    │ Fluent 2D VOF 离线参考       │
                    │ Fy_wall, Mx_ref, free surface│
                    └──────────────┬──────────────┘
                                   │ 参数识别/验证
                                   v
┌────────────────┐       ┌────────────────────────────┐
│ TruckSim 车辆端 │------>│ Slosh Provider 统一接口     │
│ unit 2 运动状态 │       │ ROM / CFD replay / CFD live │
└───────┬────────┘       └──────────────┬─────────────┘
        │                               │ ΔFy, ΔMx
        └───────────────────────────────┘
                    作用于挂车簧载质量/罐体参考点
```

`Slosh Provider` 是唯一可替换边界。TruckSim 不感知其内部是等效摆、Fluent 文件回放还是 CFD 在线参与者；上层预警与分析也只读取统一输出和元数据。

## 4. 四种提供器模式

| 模式 | 作用 | 第一篇论文地位 |
|---|---|---|
| `RIGID_ZERO` | 输出 `ΔFy=0, ΔMx=0`，形成等质量刚性液货对照 | 必需 |
| `ROM_PENDULUM` | 根据车辆运动实时计算一阶晃动增量 | 必需、主模型 |
| `CFD_REPLAY` | 按时间戳回放已完成 Fluent 的载荷增量 | 推荐验证工具 |
| `CFD_LIVE` | 每时间步与 Fluent 交换运动和载荷 | 可选扩展，不作为毕业依赖 |

所有模式使用相同函数语义：

```text
slosh_step(t, tank_motion, fill_config, state_in)
  -> delta_load, state_out, health
```

其中 `health` 至少包含数据是否有效、是否发生外推、是否收敛和时间同步误差。

## 5. 质量与载荷记账

正式方案固定采用动态增量法：

1. TruckSim 中包含罐体壳体及对应充液率的全部液体质量。
2. TruckSim 使用该充液率下的平均液体质心和等效刚体惯量。
3. Fluent 或降阶模型的总液动力不得直接再次施加。
4. 提供器只输出相对等质量刚性液货的动态增量：

\[
\Delta \mathbf L(t)
=\mathbf L_{fluid,dynamic}(t)
-\mathbf L_{fluid,rigid}(t),
\qquad
\Delta \mathbf L=
\begin{bmatrix}\Delta F_y&\Delta M_x\end{bmatrix}^{T}.
\]

5. 零激励、恒速直行和静止平衡状态下，`ΔFy` 与 `ΔMx` 必须回到数值零附近。
6. 每个充液率的 `Rigid` 与 `ROM-Slosh` 必须具有相同总质量、平均质心、平均惯量和初始轴荷。

这种记账方式避免“TruckSim 已包含全部液体质量，同时又施加完整 `-m_l a_y`”造成的质量效应重复计数。

## 6. 参数闭合

罐体几何固定后，30%、50%、70% 充液率按同一几何和液体物性计算，不单独人为指定互相矛盾的液体质量。

闭合关系为：

\[
m_l(\beta)=\rho_l\,A_l(\beta,D)\,L_{eff},
\]

其中 `β` 为体积充液率，`A_l` 为圆截面液体面积，`D` 为罐体内径，`L_eff` 为有效液舱长度。壳体质量、液体质量和附件质量分开记录。

参数表必须包含：

- 罐体内径、外径和有效液舱长度；
- 罐体壳体质量及其质心、惯量；
- 液体密度、动力黏度和参考温度；
- 各充液率液体质量、静态质心和惯量；
- 罐体相对挂车铰接点、挂车簧载质量原点和侧倾轴的位置；
- 三轴静态左右轮载与鞍座垂向载荷；
- 参数来源、单位和版本哈希。

同一真实罐体下，不要求不同充液率总质量相同；但每个充液率内部的刚性与晃动模型必须严格等质量。

## 7. 统一坐标与接口合同

接口采用规范化挂车车体坐标：`x` 向前、`y` 向左、`z` 向上，力矩按右手定则。TruckSim、Fluent 或 MATLAB 原生符号若不同，只允许在各自适配器内转换，核心模型不包含隐式负号。

### 7.1 车辆端输入到提供器

| 信号 | 单位 | 说明 |
|---|---|---|
| `time_s` | s | 单调时间戳 |
| `ay_tank_mps2` | m/s² | 罐体参考点横向加速度 |
| `roll_rad` | rad | 挂车侧倾角 |
| `roll_rate_radps` | rad/s | 挂车侧倾角速度 |
| `roll_acc_radps2` | rad/s² | 直接输出或经因果滤波估计 |
| `yaw_rate_radps` | rad/s | 挂车或单元2横摆角速度 |
| `vx_mps` | m/s | 纵向速度 |

### 7.2 提供器返回车辆端

| 信号 | 单位 | 参考点 |
|---|---|---|
| `delta_fy_N` | N | 作用于罐体/挂车的液体动态横向反力 |
| `delta_mx_Nm` | N·m | 统一换算至冻结的挂车侧倾参考轴 |
| `valid` | 0/1 | 本步结果是否可用于车辆推进 |
| `sync_error_s` | s | 提供器与车辆时间戳差 |

当前已验证的 TruckSim 信号 `Ay_2`、`Roll_2`、`AVx_2`、`Vx_2` 可作为起点；正式接口必须补齐或可靠估计侧倾角加速度，并验证 `unit 2` 确实对应挂车。

液体载荷施加在挂车簧载质量/罐体参考点，不以鞍座载荷通道替代。鞍座 `Fy_H`、`Mx_H`、`Fz_H` 只作为响应监测量。

## 8. Fluent 离线参考

1. 采用单舱、无防波板、等效圆截面罐体和单一牛顿液体。
2. 正式充液率为30%、50%、70%。
3. 30%和70%用于参数识别，50%在模型冻结前保持封存。
4. 工况为阶跃和正弦两类，每类三个强度/频率，共18个核心算例。
5. 先在70%代表工况完成三网格和至少两档时间步研究。
6. 输出保持二维单位长度量纲：`Fy N/m`、`Mx N·m/m`，再用冻结的有效长度缩放。
7. 每条记录保存体积守恒、残差/迭代状态、力矩参考点和软件版本。

现有70%二维算例和固定0.3 g、0.5 Hz UDF只作为回归模板；正式UDF必须参数化，且不直接继承旧结果作为论文证据。

## 9. ROM 识别与验证

主模型采用一个横向晃动广义坐标的一阶等效摆：

\[
\ddot\theta_l+2\zeta(\beta)\omega(\beta)\dot\theta_l
+\omega^2(\beta)\theta_l
=-\frac{a_{y,tank}}{l(\beta)}+b_\phi\ddot\phi_2.
\]

从30%和70% Fluent 数据识别 `ω(β)`、`ζ(β)`、等效质量/增益及力矩臂；用独立波形验证峰值、RMS、主频和相位。参数插值规则冻结后只打开一次50%数据进行盲测。

若一阶模型已达到预警时序所需精度，则取消不必要的残差修正；若误差稳定且会传播为显著的LTR预警时刻误差，再增加轻量因果残差修正，不升级深度网络。

## 10. TruckSim–Simulink 执行顺序

### 10.1 第一里程碑：离线文件接口

1. TruckSim运行刚性液货场景并导出罐体运动。
2. MATLAB读取运动文件并运行 `ROM_PENDULUM`。
3. 输出 `ΔFy、ΔMx` 及时间戳。
4. 通过可重复回放验证单位、符号、相位和稳定性。

### 10.2 第二里程碑：TruckSim–Simulink 在线ROM

1. TruckSim在每个通信步输出挂车运动。
2. Simulink推进降阶状态并返回动态增量载荷。
3. TruckSim将增量载荷施加到挂车簧载质量。
4. 固定步长、零阶保持和内部积分策略记录在运行清单中。
5. 通信失败或数据无效时立即终止该场景，不静默回退为零载荷。

### 10.3 可选升级A：CFD回放

保持同一接口，用 `CFD_REPLAY` 替换等效摆。用于隔离“车辆模型误差”和“晃动模型误差”，不要求实时计算。

### 10.4 可选升级B：松耦合迭代

TruckSim轨迹驱动Fluent，Fluent动态增量载荷再驱动TruckSim；重复整段场景直到关键响应变化小于冻结容差。每次迭代保存独立版本，不覆盖原轨迹。

### 10.5 可选升级C：逐时间步 CFD–车辆耦合

以 `CFD_LIVE` 实现每通信步交换运动和载荷。该模式必须先通过回放和松耦合测试，且其失败不得阻断第一篇论文。刚性罐壁条件下，成果名称使用“CFD–车辆多体动力学双向耦合”，不称为罐体结构变形FSI。

## 11. 验证与升级闸门

### 11.1 参数与静态基线

- 质量、容积和充液率代数闭合；
- 左右静态轮载对称，三轴和鞍座载荷与总重闭合；
- `Rigid` 与 `ROM-Slosh` 初始轴荷一致；
- 左右镜像工况的有符号LTR近似反号。

未通过时不得批量运行Fluent或生成正式预警标签。

### 11.2 CFD数值验收

- 三网格、至少两档时间步；
- 报告体积漂移、力和力矩峰值/RMS/主频/相位变化；
- 二维单位长度缩放和力矩换点无歧义；
- 求解失败和外推工况必须显式标记。

### 11.3 ROM与车辆响应

- 在未参与识别的波形上验证载荷幅值和相位；
- 挂车侧倾峰值相对误差持续超过15%，或主相位误差超过0.10 s时，审查车辆自由度；
- 完整轴组LTR峰值绝对误差超过0.08且能归因于牵引车滚转耦合时，才考虑将五自由度升级为六自由度。

### 11.4 升级到 CFD_LIVE 的必要条件

只有同时满足以下条件才投入逐时间步联算：

1. 论文主线的离线Fluent、ROM和TruckSim结果已经冻结且可投稿；
2. `CFD_REPLAY` 与离线原始载荷逐点一致；
3. 松耦合迭代在代表性场景收敛；
4. 时间同步、坐标转换和载荷作用点测试全部通过；
5. 额外工作不会压缩论文写作、验证和返修缓冲时间。

## 12. 正式对照与终点

每个场景至少包含：

1. `Rigid`：等质量、等静态质心、等惯量的刚性液货；
2. `ROM-Slosh`：参数化一阶晃动模型；
3. `Corrected`：仅在误差有稳定结构时增加的轻量因果修正。

主要终点为挂车完整轴组LTR首次持续越过冻结阈值的场景级时刻误差。辅助终点包括完整轴组LTR峰值、最小归一化内侧轮载、误报、漏报、提前量和失败案例。当前45°阶跃速度扫描只作为接口与边界校准，不进入正式结果矩阵。

## 13. 测试策略

1. **单位测试：**角度、加速度、力、力矩和二维长度缩放。
2. **符号测试：**左右镜像输入、零输入、恒定输入和单脉冲输入。
3. **守恒测试：**液体体积、总质量、静态轴荷和零动态增量。
4. **接口测试：**时间戳单调、步长一致、无重复/丢帧、失效显式终止。
5. **回归测试：**固定一个最小TruckSim场景、一个Fluent模板场景和一个ROM解析场景。
6. **锁定测试：**50%充液率文件在参数和预警规则冻结后才读取。

## 14. 立即执行顺序

1. 完成当前TruckSim挂车本体参数核查，记录空挂车质量、质心、惯量、轴距和铰接点。
2. 冻结罐体几何、壳体质量、液体物性和有效液舱长度。
3. 建立30%、50%、70%的质量—容积—质心—惯量—静态轴荷闭合表。
4. 为每个充液率建立TruckSim刚性液货基线并验证完整轴组轮载。
5. 参数化现有Fluent UDF并完成70%代表工况的网格/时间步验收。
6. 在离线文件接口通过前，不启动TruckSim–Simulink在线联合，也不尝试CFD_LIVE。

## 15. 完成定义

该架构设计完成实施时，应满足：

- 任何场景都能追溯其车辆、罐体、液体、提供器模式和坐标版本；
- `Rigid` 与 `ROM-Slosh` 不存在质量或静态轴荷混杂；
- Fluent、ROM和TruckSim之间的力/力矩符号及参考点经镜像和零输入测试验证；
- 第一篇论文不依赖CFD_LIVE；
- 更换提供器模式不要求修改TruckSim信号合同或上层预警代码；
- CFD_LIVE失败时，方案2成果仍完整、可复现且可投稿。
